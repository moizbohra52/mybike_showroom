# Phase 2 — open items (audit of 2026-09-23)

Phase 2 (Common UI Design System) was **not closed**: Phase 3 was started on request with these items carried over.
Source: a 6-auditor review of lib/common + tests against the Phase 2 exit criteria, the Definition of Done and ground rules G3/G5/G8,
with an independent verifier per auditor (the screens/layout verifier did not finish, so its items are marked *unverified*).
Refuted findings are omitted. Several rows describe the same root cause from different angles.

**Totals (non-refuted):** 20 blocker · 63 major · 92 minor

## Headline blockers

1. ~~`AppButton` label `Text` is not `Flexible` (lib/common/widgets/app_button.dart:70)~~ **Fixed 2026-09-24** (label wrapped in `Flexible`; `flutter test` 87/87) → the failing `mobile shell renders bottom navigation and navigates` test (132 px overflow) and overflows at 360 px in the gallery, dialogs, empty/error states.
2. Exit criterion "widget tests per component" not met — ~12 of 24 deliverables have no widget test; dark mode and viewport sizes are essentially untested; GalleryScreen has no test and omits 7 components.
